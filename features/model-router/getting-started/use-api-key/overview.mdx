## 本指南介绍什么？

本指南为您介绍使用 API Key 与 Model Router 交互的三种主要方式：

1. **直接 API 请求**：使用 cURL 或任何 HTTP 客户端直接发送 HTTP 请求
2. **最小 MVP 示例**：使用流行编程语言编写的简单、可直接运行的代码示例
3. **AI 应用集成**：将 Model Router 连接到现有 AI 工具，如 Claude Code 或 Codex CLI

## 开始之前

<Info>
在进行任何 API 调用之前，请确保您了解 API Key 可以使用哪些模型。请先查看[查看可用模型列表](/features/model-router/list-available-models)指南。
</Info>

## 使用 API Key 的三种方式

### 1. 直接 API 请求

如果您想使用 cURL、Postman 或任何 HTTP 客户端等工具直接发送请求，这是最简单的方式。

**最适合**：快速测试、自动化脚本，或需要完全控制请求的场景

**了解更多**：[直接 API 请求](/features/model-router/getting-started/use-api-key/direct-api-requests)

### 2. 最小 MVP 示例

使用 Python、Node.js 和 TypeScript 编写的可直接运行的代码示例，您可以立即复制使用。

**最适合**：构建自己的应用、学习如何集成 Model Router，或进行原型开发

**了解更多**：[最小 MVP 示例](/features/model-router/getting-started/use-api-key/minimal-mvp-examples)

### 3. AI 应用集成

将 Model Router 连接到现有的 AI 开发工具，无需编写代码。

**最适合**：配合 Model Router 使用 Claude Code 或 Codex CLI 等 AI 工具

**了解更多**：[AI 应用集成](/features/model-router/getting-started/use-api-key/ai-app-integrations)
