## 快速介绍

Model Router 提供统一的模型路由和多模态任务入口，兼容主流协议和渠道。

- 一个入口覆盖主流模型和任务，兼容 OpenAI 风格调用，无需更换 SDK
- 保留 Claude、Gemini 等原生路径，降低迁移和切换成本
- 内置稳定性保障、配额结算、通知和安全策略，帮助您在生产环境中放心集成

**Base URL**：`https://app.memorylake.cn` — OpenAI 兼容路径为 `/v1`，Claude 原生路径为 `/claude/v1`，Gemini 原生路径为 `/gemini/:version`。使用与平台其他能力相同的 `sk-…` Key 进行鉴权（[详情](/authentication)）。

<Note>
希望为您的 LLM 调用增加**记忆**能力，而不只是路由？请参阅 [Memory Router](/features/memory-router/overview)，它在相同协议之上叠加了长期记忆。
</Note>
