---
title: "列出模型"
description: "列出可调用的模型及其价格"
---

```
GET /openapi/memorylake/router/v1/models
```

列出可通过 Memory Router 调用的模型及其价格，按名称排序。`provider_type` 表示该模型走哪个 Base URL：`openai` 的模型经 `/router/openai/v1` 调用，`anthropic` 的模型经 `/router/anthropic/v1` 调用。每个站点的模型目录各自独立。

与推理接口不同，本接口使用 MemoryLake API 的响应格式：模型清单在 `data.items` 中，出错时返回 `success`、`message` 和 `error_code`。

价格按每 100 万 token 计，同时给出美元价和余额 token 数（从余额扣除的数量）。未列出的价格项表示该模型不适用这一项，不代表免费。没有 `price` 时表示该模型暂无价格，仍可调用。

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.cn/openapi/memorylake/router/v1/models' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### 错误

出错时返回 `success: false`、`message` 和 `error_code`。全部错误码见[错误码](/features/memorylake/api-reference/errors)。

| 状态码 | 含义 |
| --- | --- |
| `401` | MemoryLake API Key 缺失、无效、已停用或已过期。`error_code` 为 `UNAUTHORIZE`。 |
| `403` | 该 Key 仅允许从指定 IP 地址调用，而本次请求来自其他地址。`error_code` 为 `ACCESS_DENIED`。 |
| `429` | 来自您 IP 地址的无效 Key 请求过多。`error_code` 为 `RATE_LIMIT_EXCEEDED`。请按 `Retry-After` 等待后重试。 |
| `502` | 暂时无法获取模型清单。`error_code` 为 `INTERNAL_ERROR`。请稍后重试。 |
| `503` | 服务暂时不可用，例如正在维护。`error_code` 为 `SERVICE_UNAVAILABLE`。请稍后重试；已知需等待的时长时会返回 `Retry-After`。 |
