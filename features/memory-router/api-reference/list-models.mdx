---
title: "列出模型"
description: "列出可调用的模型及其价格"
---

```
GET /memory-router/v1/models
```

列出可通过 Memory Router 调用的模型及其价格，按协议分组：`openai` 组的模型经 `/openai/v1` 调用，`anthropic` 组的模型经 `/anthropic/v1` 调用。每个站点的模型目录各自独立。

价格按每 100 万 token 计，同时给出美元价和余额 token 数（从余额扣除的数量）。未列出的价格项表示该模型不适用这一项，不代表免费。没有 `price` 时表示该模型暂无价格，仍可调用。

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.cn/memory-router/v1/models' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>
