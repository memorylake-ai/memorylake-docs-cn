---
title: "Images"
description: "用 OpenAI 图像模型生成图片"
---

```
POST /openapi/memorylake/router/openai/v1/images/generations
```

OpenAI Images。用图像模型（例如 `gpt-image-1`）根据文本提示词生成图片。下面未列出的参数会原样传给模型。

### 请求头

<ParamField header="x-memorylake-api-key" type="string">
使用自带的模型厂商密钥（BYOK）时，在这里放 MemoryLake API Key，模型厂商密钥则放在该厂商原生的鉴权头中。您的模型厂商密钥只会转发给模型厂商，不会被保存。
</ParamField>

<ParamField header="traceparent" type="string">
W3C 链路上下文。带上后，请求会纳入您的链路，并在 `X-Trace-ID` 中返回同一个 trace id。
</ParamField>

### 请求体

<ParamField body="model" type="string" required>
图像模型名称
</ParamField>

<ParamField body="prompt" type="string" required>
图片的文字描述
</ParamField>

<ParamField body="background" type="string">
图片背景。可选值：`transparent`、`opaque`、`auto`。
</ParamField>

<ParamField body="n" type="integer">
要生成的图片数量
</ParamField>

<ParamField body="output_format" type="string">
图片文件格式。可选值：`png`、`jpeg`、`webp`。
</ParamField>

<ParamField body="quality" type="string">
渲染质量。可选值：`low`、`medium`、`high`、`auto`。
</ParamField>

<ParamField body="size" type="string">
图片尺寸，例如 `1024x1024`
</ParamField>

<RequestExample>
```bash cURL
curl -X POST 'https://app.memorylake.cn/openapi/memorylake/router/openai/v1/images/generations' \
  -H 'Authorization: Bearer sk_xxxxxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "gpt-image-1-mini",
    "prompt": "A small red circle on a white background",
    "quality": "low",
    "size": "1024x1024"
  }'
```
</RequestExample>

### 响应

<ResponseField name="created" type="integer">创建时间，Unix 秒级时间戳</ResponseField>
<ResponseField name="data" type="array">
每张图片一项
<Expandable title="Data 对象">
  <ResponseField name="b64_json" type="string">图片，base64 编码</ResponseField>
  <ResponseField name="revised_prompt" type="string">模型改写了您的提示词时实际使用的提示词</ResponseField>
</Expandable>
</ResponseField>
<ResponseField name="usage" type="object">
本次用量
<Expandable title="Usage 对象">
  <ResponseField name="input_tokens" type="integer">提示词的 token 数</ResponseField>
  <ResponseField name="output_tokens" type="integer">生成的图片 token 数</ResponseField>
  <ResponseField name="total_tokens" type="integer">输入与输出 token 之和</ResponseField>
</Expandable>
</ResponseField>

```json Success (200)
    }

    "input_tokens": 9,
    "output_tokens": 272,

  }
}
```
</ResponseExample>
