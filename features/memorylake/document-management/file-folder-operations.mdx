## 概述

本指南涵盖了在 MemoryLake 中管理文件和文件夹的所有基本操作。您将学习如何创建、上传、组织和维护您的文档集合。

## 创建文件夹

### 基本文件夹创建

<Steps>
<Step title="打开新建文件夹选项">
您可以通过以下几种方式创建新文件夹：
- 点击工具栏中的"新建文件夹"按钮
- 右键点击树中的某个文件夹，选择"新建文件夹"
- 右键点击空白区域在根级别创建

{/* SCREENSHOT: New folder button and context menu option */}
</Step>

<Step title="输入文件夹名称">
输入一个描述性的文件夹名称，然后按 Enter 或点击保存。

<Tip>
使用清晰、描述性的名称来表明文件夹的内容。好的示例："Q1-Reports"、"Research-Papers"、"Meeting-Notes"。
</Tip>
</Step>

<Step title="确认创建">
新文件夹会立即出现在文件树中。现在您可以在其中添加文件或创建子文件夹。

{/* SCREENSHOT: Newly created folder in tree view */}
</Step>
</Steps>

## 上传文件

### 单文件上传

<Steps>
<Step title="点击上传按钮">
点击工具栏中的"上传"按钮打开文件选择器。

{/* SCREENSHOT: Upload button in toolbar */}
</Step>

<Step title="选择文件">
从您的计算机中选择一个文件。支持的格式包括 PDF、Microsoft Word、Excel、PowerPoint、文本/Markdown 和图片。
</Step>

<Step title="监控进度">
在任务面板中查看上传进度。上传完成后，文件会出现在您的文件树中。
</Step>
</Steps>

### 多文件上传

<Steps>
<Step title="选择多个文件">
在文件选择器中，按住 Ctrl（Windows/Linux）或 Cmd（Mac）并点击多个文件。
或者使用 Shift+点击选择一个范围内的文件。
</Step>

<Step title="确认上传">
点击"打开"开始并发上传所有选中的文件。
</Step>

<Step title="跟踪进度">
上传面板显示每个文件的独立进度。最多可同时上传 3 个文件。

{/* SCREENSHOT: Upload progress panel with multiple files */}
</Step>
</Steps>

### 文件夹上传

<Steps>
<Step title="选择文件夹上传选项">
在上传对话框中，找到"上传文件夹"选项。
</Step>

<Step title="选择整个文件夹">
从您的计算机中选择一个文件夹。其中的所有文件和子目录都将被加入队列。
</Step>

<Step title="保留目录结构">
MemoryLake 会自动在您的云盘中重建文件夹结构，保持原有的层级关系。

{/* SCREENSHOT: Folder structure after upload showing preserved hierarchy */}

<Check>
确认文件夹结构与您的本地目录一致。所有子文件夹和文件都应该在正确的位置。
</Check>
</Step>
</Steps>

### 拖拽上传

最快捷的文件上传方式：

1. **打开文件资源管理器/Finder** — 在您的计算机上打开
2. **找到您的文件** — 导航到您要上传的文件
3. **拖拽到 MemoryLake** — 将文件直接拖拽到文件树视图上
4. **放置到目标文件夹** — 放到特定文件夹中进行上传，或放到空白区域上传到根目录

{/* SCREENSHOT: Drag-and-drop operation in progress */}

<Tip>
一次拖拽多个文件可进行批量上传。
</Tip>

## 重命名项目

### 重命名文件或文件夹

<Steps>
<Step title="发起重命名">
右键点击文件或文件夹，从上下文菜单中选择"重命名"。

{/* SCREENSHOT: Context menu with rename option */}
</Step>

<Step title="编辑名称">
名称变为可编辑状态，输入新名称。
</Step>

<Step title="保存更改">
按 Enter 保存或按 Escape 取消。项目会在文件树中立即更新。
</Step>
</Steps>

## 移动项目

### 拖拽移动

最直观的文件和文件夹移动方式：

1. **点击并按住**您要移动的项目
2. **拖拽到目标**文件夹
3. 当目标文件夹高亮显示时**松开**
4. **确认**项目已出现在新位置

{/* SCREENSHOT: Drag-and-drop move operation */}

### 通过对话框移动

如需更精确的控制：

<Steps>
<Step title="打开移动对话框">
右键点击项目，从上下文菜单中选择"移动"。
</Step>

<Step title="导航到目标位置">
在移动对话框中，浏览文件树找到目标文件夹。

{/* SCREENSHOT: Move dialog with folder tree selector */}
</Step>

<Step title="选择并确认">
点击目标文件夹，然后点击"移动"完成操作。

<Check>
项目会立即出现在新位置，并从原位置移除。
</Check>
</Step>
</Steps>

### 移动行为

- **文件夹**：移动文件夹会同时移动其所有内容
- **权限**：移动不会影响项目关联
- **评论**：评论随项目一起移动

## 下载文件

### 下载单个文件

<Steps>
<Step title="选择文件">
在文件树中点击一个文件以选中它。
</Step>

<Step title="下载">
右键点击选择"下载"，或点击工具栏中的下载按钮。
</Step>

<Step title="保存到本地">
您的浏览器会将文件下载到默认的下载文件夹。
</Step>
</Steps>

## 删除项目

### 删除文件或文件夹

<Steps>
<Step title="选择要删除的项目">
点击您要删除的文件或文件夹。
</Step>

<Step title="发起删除">
右键点击选择"删除"。

{/* SCREENSHOT: Delete confirmation dialog */}
</Step>

<Step title="确认删除">
会出现一个确认对话框。核实项目名称后点击"删除"确认。

<Warning>
删除操作是永久性的，无法撤销。已删除的项目不会移入回收站。
</Warning>
</Step>

<Step title="确认移除">
项目会立即从文件树中消失。
</Step>
</Steps>

### 删除包含内容的文件夹

当您删除一个文件夹时：
- **所有内容都会被删除**：所有文件和子文件夹将被永久移除
- **需要确认**：非空文件夹需要额外确认


## 最佳实践

<AccordionGroup>
<Accordion title="组织您的文档">
- 在上传前创建合理的文件夹层级
- 将相关文档归组在一起
- 使用一致的命名规范
- 保持文件夹结构相对扁平（3-5 层）
</Accordion>

<Accordion title="高效上传">
- 使用文件夹上传保留目录结构
- 将相关文件一起上传
- 使用拖拽方式快速上传
- 监控大文件的上传进度
</Accordion>

<Accordion title="维护您的云盘">
- 定期查看并删除不再使用的文件
- 保持文件夹名称具有描述性和时效性
- 使用评论为文件添加上下文
- 下载重要文件作为备份
</Accordion>

</AccordionGroup>
