---
title: "批量遗忘事实"
description: "在单个请求中将多个事实标记为已遗忘"
---

```
POST /openapi/memorylake/api/v3/workspaces/{workspaceId}/projects/{projectId}/memories/facts/forget
```

在单个请求中将多个事实标记为已遗忘（已过期）。与[遗忘事实](/features/memorylake/api-reference/facts/forget-fact)类似，这是一种软删除——事实仍可用于审计目的，但会从未来的检索和搜索中排除。

<Note>
**所需权限：** `project:mem_delete`
</Note>

### 路径参数

<ParamField path="workspaceId" type="string" required>
工作空间 ID
</ParamField>

<ParamField path="projectId" type="string" required>
项目 ID
</ParamField>

### 请求体

<ParamField body="ids" type="array" required>
要遗忘的事实 ID 数组
</ParamField>

<RequestExample>
```bash cURL
curl -X POST 'https://app.memorylake.cn/openapi/memorylake/api/v3/workspaces/ws-fe314186ccd18cde04d6af48a5afd79f/projects/proj_a1b2c3d4e5f6/memories/facts/forget' \
  -H 'Authorization: Bearer sk_xxxxxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "ids": [
      "fact-2fe07aee0058d141c744685a2d7272be",
      "fact-044bdc2ffcf8c7915aa9e79d5a10efd4",
      "fact_7g9h0i1j2k3l"
    ]
  }'
```
</RequestExample>

### 响应

成功时返回空的 `data` 对象。

<ResponseExample>
```json Success (200)
{
  "success": true,
  "data": {}
}
```
</ResponseExample>
