---
title: "获取项目记忆设置"
description: "读取决定项目记忆记录哪些内容的设置"
---

```
GET /openapi/memorylake/api/v3/workspaces/{workspaceId}/projects/{projectId}/settings
```

返回项目的记忆设置。记忆设置决定项目的记忆此后如何运作。目前只有一项：`fact_instruction`（事实提取说明），写明这份记忆是关于什么的、不包含什么。MemoryLake 每次向项目中提取事实时都会读取它，从而收窄被记录的主题范围。在控制台中，它对应项目「记忆设置」里的「记忆抽取说明」。

`fact_instruction` 为空字符串表示尚未设置，当前生效的是项目的内置默认值。

<Note>
**所需权限：** `project:read`
</Note>

### 路径参数

<ParamField path="workspaceId" type="string" required>
工作空间标识符
</ParamField>

<ParamField path="projectId" type="string" required>
项目标识符
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.cn/openapi/memorylake/api/v3/workspaces/ws-8001856949ad4f6a5b6226f415ffa877/projects/proj-b93e8d95a8705bcc4ec42a65ba4cc7f8/settings' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### 响应

<ResponseField name="data" type="object">
<Expandable title="记忆设置对象">
  <ResponseField name="fact_instruction" type="string">这份记忆是关于什么的、不包含什么，Markdown 格式，最多 2000 个字符。空字符串表示尚未设置，当前生效的是内置默认值。</ResponseField>
</Expandable>
</ResponseField>

<ResponseExample>
```json Success (200)
{
  "success": true,
  "data": {
    "fact_instruction": "记录文档和命令行工具的使用方式。\n\n## 包括\n- 用户运行的命令及传入的参数\n- 用户阅读的文档页面及带着的问题\n\n## 不包括\n- 任何人的个人偏好"
  }
}
```

```json Not set (200)
{
  "success": true,
  "data": {
    "fact_instruction": ""
  }
}
```
</ResponseExample>
