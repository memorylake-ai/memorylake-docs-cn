---
title: "删除工作空间"
description: "删除工作空间"
---

```
DELETE /openapi/memorylake/api/v3/workspaces/{id}
```

<Warning>
这是一个破坏性操作，且不可撤销。工作空间及其中的一切（项目、会话、Actor 与 Agent 绑定，以及所有其他工作空间范围的数据）将无法再通过 API 或控制台访问。删除只是让这些数据不再可访问，并不会抹除已存储的内容。
</Warning>

通过 ID 删除工作空间。

<Note>
**所需权限：** `workspace:delete`
</Note>

### 路径参数

<ParamField path="id" type="string" required>
工作空间 ID
</ParamField>

<RequestExample>
```bash cURL
curl -X DELETE 'https://app.memorylake.cn/openapi/memorylake/api/v3/workspaces/ws_abc123def456' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### 响应

<ResponseField name="success" type="boolean">表示请求是否成功</ResponseField>
<ResponseField name="message" type="string">人类可读的状态消息</ResponseField>

<ResponseExample>
```json Success (200)
{
  "success": true,
  "message": "Operation completed successfully"
}
```
</ResponseExample>
