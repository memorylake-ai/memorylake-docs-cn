---
title: "转让所有权"
description: "将此组织团队的所有权转让给另一名活跃的真人成员"
---

```
POST /openapi/memorylake/admin/v1/team/transfer-ownership
```

将此组织团队的所有权转让给另一名活跃的真人成员。转让后，调用方成为管理员，不能再执行仅限所有者的操作。

<Warning>
**高风险操作。** 调用后立即生效。调用前请先读完上面说明的影响。
</Warning>

<Note>
**所需权限：** 仅团队所有者
</Note>

### 请求头

<ParamField header="Idempotency-Key" type="string">
可选。同一调用方使用相同值重试会重放首次结果。
</ParamField>

### 请求体

<ParamField body="new_owner_principal_id" type="string" required>
将成为团队所有者的有效真人成员的 `principal_id`
</ParamField>

<RequestExample>
```bash cURL
curl -X POST 'https://app.memorylake.cn/openapi/memorylake/admin/v1/team/transfer-ownership' \
  -H 'Authorization: Bearer sk_xxxxxx' \
  -H 'Idempotency-Key: 7c1d2e3f-0a9b-4c8d-b7e6-f5a4d3c2b1a0' \
  -H 'Content-Type: application/json' \
  -d '{
    "new_owner_principal_id": "670048c3ad268485e39c944bbf532eb8"
  }'
```
</RequestExample>

### 响应

<ResponseField name="data" type="object">
<Expandable title="Transfer Team Ownership 对象">
  <ResponseField name="new_owner_principal_id" type="string">新所有者的 `principal_id`</ResponseField>
  <ResponseField name="previous_owner_principal_id" type="string">原所有者的 `principal_id`</ResponseField>
  <ResponseField name="tenant_id" type="string">团队 ID</ResponseField>
</Expandable>
</ResponseField>
