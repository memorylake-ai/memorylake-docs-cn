---
title: "列出邀请"
description: "列出团队的邀请，按时间倒序，可按状态和邮箱地址筛选（重复 `email=` 可一次检查多个地址）"
---

```
GET /openapi/memorylake/admin/v1/invitations
```

列出团队的邀请，按时间倒序，可按状态和邮箱地址筛选（重复 `email=` 可一次检查多个地址）。

<Note>
**所需权限：** `member:invite`
</Note>

### 查询参数

<ParamField query="page_size" type="integer" default="20">
每页条目数（1–100）
</ParamField>

<ParamField query="continuation_token" type="string">
上一页返回的令牌。不透明——请勿自行构造或解析。
</ParamField>

<ParamField query="status" type="string">
仅返回此状态的邀请。可选值：`pending`、`accepted`、`rejected`、`expired`、`revoked`。
</ParamField>

<ParamField query="email" type="array">
仅返回这些地址的邀请（不区分大小写）。如需多个，请重复该参数。
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.cn/openapi/memorylake/admin/v1/invitations' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### 响应

<ResponseField name="data" type="object">
<Expandable title="Load More Response Invitation 对象">
  <ResponseField name="items" type="array">
  当前页的条目列表
  <Expandable title="Invitation 对象">
    <ResponseField name="created_at" type="integer">首次邀请时间，Unix 秒级时间戳</ResponseField>
    <ResponseField name="email" type="string">被邀请人邮箱地址（规范化为小写）</ResponseField>
    <ResponseField name="expires_at" type="integer">当前邀请邮件的过期时间，Unix 秒级时间戳</ResponseField>
    <ResponseField name="id" type="string">此邀请的稳定标识符</ResponseField>
    <ResponseField name="role" type="string">受邀人接受邀请后将持有的角色：`tenant_admin` | `tenant_member` | &lt;自定义角色&gt;</ResponseField>
    <ResponseField name="status" type="string">邀请状态。可选值：`pending`、`accepted`、`rejected`、`expired`、`revoked`。</ResponseField>
    <ResponseField name="accepted_at" type="integer">接受时间，Unix 秒级时间戳。仅在已接受时返回。</ResponseField>
    <ResponseField name="accepted_principal_id" type="string">此邀请产生的成员的 `principal_id`。仅在已接受时返回。</ResponseField>
    <ResponseField name="last_invited_at" type="integer">最近一次发送邀请邮件的时间，Unix 秒级时间戳。早于此字段引入的记录中省略。</ResponseField>
  </Expandable>
  </ResponseField>
  <ResponseField name="continuation_token" type="string">用于获取下一页的令牌；最后一页不返回</ResponseField>
  <ResponseField name="total" type="integer">所有分页中符合筛选条件的条目总数；无法获取计数时省略</ResponseField>
</Expandable>
</ResponseField>
