---
title: "撤销邀请"
description: "撤销一个待处理的邀请；其邮件链接随即失效"
---

```
DELETE /openapi/memorylake/admin/v1/invitations/{id}
```

撤销一个待处理的邀请；其邮件链接随即失效。已接受的邀请无法撤销——请改为移除该成员。

<Note>
**所需权限：** `member:invite`
</Note>

### 路径参数

<ParamField path="id" type="string" required>
邀请的标识符
</ParamField>

### 请求头

<ParamField header="Idempotency-Key" type="string">
可选。使用相同值重试会重放首次结果。
</ParamField>

<RequestExample>
```bash cURL
curl -X DELETE 'https://app.memorylake.cn/openapi/memorylake/admin/v1/invitations/9d971b8b5813eb1ecceec31354c101b4' \
  -H 'Authorization: Bearer sk_xxxxxx' \
  -H 'Idempotency-Key: 7c1d2e3f-0a9b-4c8d-b7e6-f5a4d3c2b1a0'
```
</RequestExample>

### 响应

<ResponseExample>
```json Success (200)
{
  "success": true,
  "message": "Operation completed successfully",
  "data": {}
}
```
</ResponseExample>

### 错误

出错时返回 `success: false`、`message` 和 `error_code`。全部错误码见[错误码](/features/memorylake/api-reference/errors)。

| 状态码 | 含义 |
| --- | --- |
| `401` | API Key 缺失、无效、已停用或已过期 |
| `403` | 该 Key 无权执行此操作 |
| `404` | 资源不存在 |
| `409` | 请求与当前状态冲突，例如重复或已达上限 |
| `422` | 请求体或参数未通过校验 |
| `429` | 请求过多，请按 `Retry-After` 等待后重试 |
| `500` | 服务端错误 |
| `503` | 暂时不可用，请稍后重试 |
