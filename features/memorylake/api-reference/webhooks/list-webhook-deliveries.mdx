---
title: "列出投递记录"
description: "列出某个 Webhook 最近 15 天的投递记录，按事件发生时间倒序"
---

```
GET /openapi/memorylake/admin/v1/webhooks/{webhook_id}/deliveries
```

列出某个 Webhook 最近 15 天的投递记录，按事件发生时间倒序。一条投递记录是发往该 Webhook 的一个事件；自动重试与重新发送都是同一条记录的后续尝试。

<Note>
**所需权限：** `webhook:manage`
</Note>

### 路径参数

<ParamField path="webhook_id" type="string" required>
Webhook 的标识
</ParamField>

### 查询参数

<ParamField query="result" type="string">
只看该结果的投递记录；`failed` 包含仍在重试的。可选值：`succeeded`、`failed`、`skipped`。
</ParamField>

<ParamField query="event_type" type="string">
只看该事件类型
</ParamField>

<ParamField query="page_size" type="integer" default="20">
每页条数（1–100）
</ParamField>

<ParamField query="continuation_token" type="string">
上一页返回的令牌
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.cn/openapi/memorylake/admin/v1/webhooks/16522a01eaa7b9feef48caafb0b487a5/deliveries' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

    <ResponseField name="status" type="string">`pending` = 已排队，尚无结果；`retrying` = 已失败，下一次重试在 `next_attempt_at`；`skipped` = Webhook 已停用，未发送。可选值：`pending`、`retrying`、`succeeded`、`failed`、`skipped`。</ResponseField>

    <ResponseField name="status_code" type="integer">最近一次响应的 HTTP 状态码</ResponseField>
  </Expandable>
  </ResponseField>

  <ResponseField name="total" type="integer">所有分页中符合筛选条件的条目总数；无法获取计数时省略</ResponseField>
</Expandable>
</ResponseField>

### 错误

出错时返回 `success: false`、`message` 和 `error_code`。全部错误码见[错误码](/features/memorylake/api-reference/errors)。

| 状态码 | 含义 |
| --- | --- |
| `400` | 参数或请求体无效 |
| `401` | API Key 缺失、无效、已停用或已过期 |
| `403` | 该 Key 无权执行此操作 |
| `404` | 资源不存在 |
| `422` | 请求体或参数未通过校验 |
| `429` | 请求过多，请按 `Retry-After` 等待后重试 |
| `500` | 服务端错误 |
