---
title: "创建会话"
description: "在工作空间中创建新会话"
---

```
POST /openapi/memorylake/api/v3/workspaces/{workspaceId}/memories/conversations
```

在工作空间中创建新会话。会话将相关消息组织在一起，以便 MemoryLake 从交互中提取结构化事实。您必须通过 `rw_project_ids` 指定一个读写项目 -- 这是存储提取的事实和记忆的项目。

<Note>
**所需权限：** 工作空间上需要 `workspace:conv_create`，此外按您指名的对象各需一组——`rw_project_ids` 里的每个项目需要 `project:mem_add`、`project:doc_add`、`project:mem_search`、`project:doc_search`；`actor_ids` 里的每个 Actor 需要 `workspace_actor:fact_add` 与 `workspace_actor:fact_search`；`agent_ids` 里的每个 Agent 需要 `workspace_agent:fact_add` 与 `workspace_agent:fact_search`。会话既写入记忆也要读回，所以每个参与者的「写」和「搜」两半都要。
</Note>

### 路径参数

<ParamField path="workspaceId" type="string" required>
工作空间标识符
</ParamField>

### 请求体

<ParamField body="custom_id" type="string" required>
这个会话在**您自己系统里已有的标识符**。在您的租户内必须唯一。后续请求带上 `by_custom_id=true`，即可用它代替 `id` 来访问。参见[您自己的标识符](/features/memorylake/api-reference/overview#您自己的标识符)。
</ParamField>

<ParamField body="kind" type="string" required>
会话类型：`DIRECT`（一对一）或 `GROUP`（多参与者）。
</ParamField>

<ParamField body="rw_project_ids" type="array" required>
会话读取上下文和写入事实的读写项目。需要恰好一个项目 ID。
</ParamField>

<ParamField body="actor_ids" type="array" required>
参与本次会话的 Actor。`actor_ids` 与 `agent_ids` 合起来至少要有一个参与者：消息归属于参与者，记忆也在参与者身上积累。
</ParamField>

<ParamField body="agent_ids" type="array of strings">
参与本次会话的 Agent。
</ParamField>

<ParamField body="name" type="string">
会话的显示名称
</ParamField>

<ParamField body="metadata" type="object">
附加到会话的任意键值元数据
</ParamField>

<RequestExample>
```bash cURL
curl -X POST 'https://app.memorylake.cn/openapi/memorylake/api/v3/workspaces/ws-fe314186ccd18cde04d6af48a5afd79f/memories/conversations' \
  -H 'Authorization: Bearer sk_xxxxxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "custom_id": "session-20250601-042",
    "name": "Product Feedback Call",
    "kind": "DIRECT",
    "rw_project_ids": ["proj-b93e8d95a8705bcc4ec42a65ba4cc7f8"],
    "metadata": {
      "channel": "zoom",
      "language": "en"
    },
    "actor_ids": ["actor-93688d5ec8d2e98701be3d5554cbc455", "actor-9831773f1353358f4196b22505d879e0"]
  }'
```
</RequestExample>
