---
title: "获取分析模型"
description: "通过 ID 或自定义 ID 获取分析模型"
noindex: true
---

```
GET /openapi/memorylake/api/v3/workspaces/{workspaceId}/analysis-models/{modelId}
```

通过 ID 获取分析模型。如需用创建时设置的 `custom_id` 查找，请把 `by_custom_id` 设为 `true`，并把自定义 ID 作为路径参数传入。

如需读取模型包含的知识，请调用[列出知识条目](/features/memorylake/api-reference/database/analysis-models/list-knowledge-entries)。

<Note>
**所需权限：** `analysis_model:read`
</Note>

### 路径参数

<ParamField path="workspaceId" type="string" required>
工作空间 ID
</ParamField>

<ParamField path="modelId" type="string" required>
分析模型 ID；当 `by_custom_id` 为 `true` 时为模型的 `custom_id`
</ParamField>

### 查询参数

<ParamField query="by_custom_id" type="boolean" default="false">
设为 `true` 时按 `custom_id` 而不是 ID 查找模型
</ParamField>

<RequestExample>
```bash By model ID
curl -X GET 'https://app.memorylake.cn/openapi/memorylake/api/v3/workspaces/ws-8001856949ad4f6a5b6226f415ffa877/analysis-models/am-9d3f7b1e5a2c4d8f6b0e3a7c9d1f5b2e' \
  -H 'Authorization: Bearer sk_xxxxxx'
```

```bash By custom ID
curl -X GET 'https://app.memorylake.cn/openapi/memorylake/api/v3/workspaces/ws-8001856949ad4f6a5b6226f415ffa877/analysis-models/sales-qa?by_custom_id=true' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### 响应

<ResponseField name="data" type="object">
<Expandable title="分析模型对象">
  <ResponseField name="id" type="string">分析模型标识符，请把它当作不透明字符串处理。</ResponseField>
  <ResponseField name="name" type="string">显示名称</ResponseField>
  <ResponseField name="description" type="string">自由格式的描述</ResponseField>
  <ResponseField name="type" type="string">模型遵循的模板，例如 `ASK_DATA`。它决定模型接受哪些类型的知识。</ResponseField>
  <ResponseField name="schemas" type="array">模型覆盖的 schema，继承自其数据源</ResponseField>
  <ResponseField name="custom_id" type="string">您为这个模型设置的自定义标识符（如果设置过）</ResponseField>
  <ResponseField name="db_datasource_id" type="string">模型所基于的数据源</ResponseField>
  <ResponseField name="workspace_id" type="string">模型所属的工作空间</ResponseField>
  <ResponseField name="fork_from" type="string">这个模型派生自的源模型。从零创建的模型不返回该字段。它只是来源记录，不是依赖：源模型被删除后它仍指向源模型，此时用这个 ID 查询会返回「未找到」。</ResponseField>
  <ResponseField name="created_at" type="string">创建时间戳</ResponseField>
  <ResponseField name="updated_at" type="string">最后更新时间戳</ResponseField>
</Expandable>
</ResponseField>
