---
title: "获取数据源"
description: "通过 ID 或自定义 ID 获取数据源及其构建状态"
noindex: true
---

```
GET /openapi/memorylake/api/v3/workspaces/{workspaceId}/db-datasources/{datasourceId}
```

获取数据源，包括它覆盖的 schema 和索引的状态。如需用创建时设置的 `custom_id` 查找，请把 `by_custom_id` 设为 `true`，并把自定义 ID 作为路径参数传入。

数据源没有 `status` 字段。索引的状态要从三个版本字段读取：

| 字段情况 | 含义 |
|---|---|
| `build_version` 为空 | 索引从未构建过。 |
| `building_version` 非空 | 正在构建。请持续轮询这个接口，直到 `building_version` 重新变为空，即表示构建结束。 |
| `data_version` 非空且与 `build_version` 不同 | 索引落后于数据。请重新[构建索引](/features/memorylake/api-reference/database/datasources/build-datasource-index)。 |

<Note>
**所需权限：** `db_datasource:read`
</Note>

### 路径参数

<ParamField path="workspaceId" type="string" required>
工作空间 ID
</ParamField>

<ParamField path="datasourceId" type="string" required>
数据源 ID；当 `by_custom_id` 为 `true` 时为数据源的 `custom_id`
</ParamField>

### 查询参数

<ParamField query="by_custom_id" type="boolean" default="false">
设为 `true` 时按 `custom_id` 而不是 ID 查找数据源
</ParamField>

<RequestExample>
```bash By datasource ID
curl -X GET 'https://app.memorylake.cn/openapi/memorylake/api/v3/workspaces/ws-8001856949ad4f6a5b6226f415ffa877/db-datasources/dbds-4b8e2f6a1c9d4e7b8a3f5c2d6e9b1a7c' \
  -H 'Authorization: Bearer sk_xxxxxx'
```

```bash By custom ID
curl -X GET 'https://app.memorylake.cn/openapi/memorylake/api/v3/workspaces/ws-8001856949ad4f6a5b6226f415ffa877/db-datasources/sales-ds?by_custom_id=true' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### 响应

<ResponseField name="data" type="object">
<Expandable title="数据源对象">
  <ResponseField name="id" type="string">数据源标识符，请把它当作不透明字符串处理。</ResponseField>
  <ResponseField name="name" type="string">显示名称</ResponseField>
  <ResponseField name="description" type="string">自由格式的描述</ResponseField>
  <ResponseField name="schemas" type="array">这个数据源覆盖的 schema。目前只包含一项，且不能修改。</ResponseField>
  <ResponseField name="workspace_id" type="string">这个数据源所属的工作空间</ResponseField>
  <ResponseField name="db_connection_id" type="string">这个数据源读取数据所用的连接</ResponseField>
  <ResponseField name="custom_id" type="string">您为这个数据源设置的自定义标识符（如果设置过）</ResponseField>
  <ResponseField name="table_filter_rule" type="string">正则表达式，决定 schema 中哪些数据表进入索引。`.*` 表示全部数据表。</ResponseField>
  <ResponseField name="database_count" type="integer">当前使用这个数据源的数据库记忆数量。大于零时不能删除该数据源。</ResponseField>
  <ResponseField name="build_version" type="string">最近一次构建完成的索引版本。首次构建完成之前为空。</ResponseField>
  <ResponseField name="building_version" type="string">正在构建的索引版本。没有构建在进行时为空。</ResponseField>
  <ResponseField name="data_version" type="string">数据版本，用于判断索引是否最新。当它非空且与 `build_version` 不同时，说明索引落后于数据，需要重新构建。</ResponseField>
  <ResponseField name="created_at" type="string">创建时间戳</ResponseField>
  <ResponseField name="updated_at" type="string">最后更新时间戳</ResponseField>
</Expandable>
</ResponseField>
