---
title: "删除数据库记忆"
description: "从项目中移除数据库记忆"
noindex: true
---

```
DELETE /openapi/memorylake/api/v3/workspaces/{workspaceId}/projects/{projectId}/memories/databases/{databaseId}
```

从项目中移除数据库记忆。数据源、分析模型以及您的数据库本身都不受影响。

只要还有数据库记忆读取某个数据源，该数据源就不能删除；只要还有数据库记忆绑定某个分析模型，该分析模型也不能删除。要[删除数据源](/features/memorylake/api-reference/database/datasources/delete-datasource)，请先删除读取它的记忆。要[删除分析模型](/features/memorylake/api-reference/database/analysis-models/delete-analysis-model)，请先删除绑定它的记忆，或用[更新数据库记忆](/features/memorylake/api-reference/database/database-memories/update-database-memory)解除绑定。

<Note>
**所需权限：** 项目上的 `project:dbset_delete`
</Note>

<Warning>
此操作不可撤销。记忆的指引，以及 MemoryLake 为这个记忆从数据库准备的全部内容，都会随之删除。
</Warning>

### 路径参数

<ParamField path="workspaceId" type="string" required>
项目所属的工作空间 ID
</ParamField>

<ParamField path="projectId" type="string" required>
项目 ID
</ParamField>

<ParamField path="databaseId" type="string" required>
数据库记忆 ID
</ParamField>

<RequestExample>
```bash cURL
curl -X DELETE 'https://app.memorylake.cn/openapi/memorylake/api/v3/workspaces/ws-8001856949ad4f6a5b6226f415ffa877/projects/proj-b93e8d95a8705bcc4ec42a65ba4cc7f8/memories/databases/doc-2e6a9c4f8b1d4a7e9c3b5d8f0a2c4e6b' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>
