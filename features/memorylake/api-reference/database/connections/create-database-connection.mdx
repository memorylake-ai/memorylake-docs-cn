---
title: "创建数据库连接"
description: "保存访问数据库的方式及其凭据"
noindex: true
---

```
POST /openapi/memorylake/api/v3/db-connections
```

保存访问数据库的方式和读取它所需的凭据。连接属于您的团队，可以为任意工作空间中的数据源提供服务。

密码只写不读：任何接口都不会返回它。如需先检查凭据，请调用[测试数据库连通性](/features/memorylake/api-reference/database/connections/test-database-connectivity)。

<Note>
**所需权限：** `dbconn:add`
</Note>

### 请求体

<ParamField body="name" type="string" required>
显示名称
</ParamField>

<ParamField body="host" type="string" required>
服务器主机名或地址
</ParamField>

<ParamField body="port" type="integer" default="5432">
服务器端口，取值 1 到 65535
</ParamField>

<ParamField body="database" type="string" required>
要读取的数据库名
</ParamField>

<ParamField body="username" type="string" required>
用于认证的用户名
</ParamField>

<ParamField body="password" type="string" required>
用于认证的密码。任何接口都不会返回它。
</ParamField>

<ParamField body="description" type="string">
自由格式的描述
</ParamField>

<ParamField body="custom_id" type="string">
这个连接在您自己系统里的标识符，最长 255 个字符。在您的租户内必须唯一，设置后不能修改，且不能以 `_sys_` 开头。调用[获取数据库连接](/features/memorylake/api-reference/database/connections/get-database-connection)时带上 `by_custom_id=true`，即可用它查找连接。参见[您自己的标识符](/features/memorylake/api-reference/overview#您自己的标识符)。
</ParamField>

<RequestExample>
```bash cURL
curl -X POST 'https://app.memorylake.cn/openapi/memorylake/api/v3/db-connections' \
  -H 'Authorization: Bearer sk_xxxxxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "name": "Sales warehouse",
    "description": "Read-only replica of the sales database",
    "host": "pg.internal.example.com",
    "port": 5432,
    "database": "sales",
    "username": "analytics_ro",
    "password": "your-database-password",
    "custom_id": "sales-warehouse"
  }'
```
</RequestExample>

### 响应

<ResponseField name="data" type="object">
<Expandable title="连接对象">
  <ResponseField name="id" type="string">数据库连接标识符，请把它当作不透明字符串处理。</ResponseField>
  <ResponseField name="name" type="string">显示名称</ResponseField>
  <ResponseField name="description" type="string">自由格式的描述</ResponseField>
  <ResponseField name="host" type="string">服务器主机名或地址</ResponseField>
  <ResponseField name="port" type="integer">服务器端口</ResponseField>
  <ResponseField name="username" type="string">连接用于认证的用户名</ResponseField>
  <ResponseField name="database" type="string">要读取的数据库名</ResponseField>
  <ResponseField name="custom_id" type="string">您为这个连接设置的自定义标识符（如果设置过）</ResponseField>

  <ResponseField name="created_at" type="string">创建时间戳</ResponseField>
  <ResponseField name="updated_at" type="string">最后更新时间戳</ResponseField>
</Expandable>
</ResponseField>
