---
title: "更新 API Key"
description: "更改 API Key 的名称、状态、过期时间、IP 限制或路由分组"
---

```
PATCH /openapi/memorylake/admin/v1/api-keys/{id}
```

更改 API Key 的名称、状态、过期时间、IP 限制或路由分组。仅更改您发送的字段；不接受 `null`——如需清空，请发送 `[]` 或 `""`。已过期的 Key 只有同时设置未来的 `expires_at` 才能启用；所有者已被删除的 Key 不可启用；用于本次请求的 Key 不能禁用自身。路由分组须为公开分组或 Key 所有者自己的分组。

<Note>
**所需权限：** `service_account:update`（仅本人的 Key）或 `service_account:update`（全部 Key）
</Note>

### 路径参数

<ParamField path="id" type="string" required>
API Key 的标识符
</ParamField>

### 请求体

<ParamField body="allowed_ips" type="array">
替换 IP / CIDR 限制。`[]` 表示移除。
</ParamField>

<ParamField body="backup_group" type="string">
备用模型路由分组。传 `""` 表示清除。
</ParamField>

<ParamField body="expires_at" type="integer">
新的过期时间，Unix 秒级时间戳。0 = 永不过期。
</ParamField>

<ParamField body="group" type="string">
模型路由分组。传 `""` 可清除。
</ParamField>

<ParamField body="name" type="string">
新显示名称。用量明细按每次请求时 Key 的名称保存，因此重命名会使该 Key 的历史记录分开。
</ParamField>

<ParamField body="status" type="string">
启用或停用该 Key。已过期的 Key 只有同时设置一个未来的 `expires_at` 时才能启用。可选值：`enabled`、`disabled`。
</ParamField>

<RequestExample>
```bash cURL
curl -X PATCH 'https://app.memorylake.cn/openapi/memorylake/admin/v1/api-keys/9d971b8b5813eb1ecceec31354c101b4' \
  -H 'Authorization: Bearer sk_xxxxxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "allowed_ips": [
      "example"
    ],
    "backup_group": "example",
    "expires_at": 1760000000,
    "group": "example",
    "name": "Example name",
    "status": "enabled"
  }'
```
</RequestExample>

    <ResponseField name="principal_id" type="string">成员的 `principal_id`（参见 GET /members）</ResponseField>

### 错误

出错时返回 `success: false`、`message` 和 `error_code`。全部错误码见[错误码](/features/memorylake/api-reference/errors)。

| 状态码 | 含义 |
| --- | --- |
| `400` | 参数或请求体无效 |
| `401` | API Key 缺失、无效、已停用或已过期 |
| `403` | 该 Key 无权执行此操作 |
| `404` | 资源不存在 |
| `409` | 请求与当前状态冲突，例如重复或已达上限 |
| `422` | 请求体或参数未通过校验 |
| `429` | 请求过多，请按 `Retry-After` 等待后重试 |
| `500` | 服务端错误 |
