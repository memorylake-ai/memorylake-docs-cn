---
title: "获取角色访问范围"
description: "按资源类型返回该角色的持有者是可访问所有实例（`all` 模式）还是仅可访问所列实例（`instances` 模式）"
---

```
GET /openapi/memorylake/admin/v1/roles/{role_key}/access-scope
```

按资源类型返回该角色的持有者是可访问所有实例（`all` 模式）还是仅可访问所列实例（`instances` 模式）。所有者角色没有范围（409）。`ETag` 头标识此状态，可用于条件式[设置角色访问范围](/features/memorylake/api-reference/access-control/set-role-access-scope)。

<Note>
**所需权限：** `policy:manage`
</Note>

### 路径参数

<ParamField path="role_key" type="string" required>
角色键（`key`）
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.cn/openapi/memorylake/admin/v1/roles/data_analyst/access-scope' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### 响应

<ResponseField name="data" type="object">
<Expandable title="Role Access Scope 对象">
  <ResponseField name="role_key" type="string">角色</ResponseField>
  <ResponseField name="scopes" type="array">
  每个可设范围的资源类型一项
  <Expandable title="Access Scope Entry 对象">
    <ResponseField name="mode" type="string">`all` 表示所有实例；`instances` 表示仅列出的实例</ResponseField>
    <ResponseField name="resource_type" type="string">资源类型，例如 `memorylake:project`（参见 `GET /permission-catalog`）</ResponseField>
    <ResponseField name="available_actions" type="array">只读。成员角色对该类型授予的实例级操作——即范围条目最多可允许的操作。</ResponseField>
    <ResponseField name="instances" type="array">
    `mode` 为 `instances` 时的实例列表
    <Expandable title="Access Scope Instance 对象">
      <ResponseField name="id" type="string">实例 ID，与数据 API 返回的一致</ResponseField>
      <ResponseField name="actions" type="array">该实例上允许的操作。省略则为该成员角色允许的全部操作。</ResponseField>
      <ResponseField name="effective_actions" type="array">只读。成员当前角色仍授予的操作子集。</ResponseField>
      <ResponseField name="permission_level" type="string">只读。当 `via_permission_level` 为 true 时的权限级别。可选值：`read`、`write`、`manage`。</ResponseField>
      <ResponseField name="shadowed_actions" type="array">只读。此处存储但成员当前角色已不再授予的操作。</ResponseField>
      <ResponseField name="via_permission_level" type="boolean">只读。成员通过在此实例上授予的权限级别访问该实例，而非通过此范围。写入时可原样回传；此类实例会被跳过。</ResponseField>
      <ResponseField name="workspace_id" type="string">项目实例的父工作空间。写入项目实例时必填。</ResponseField>
    </Expandable>
    </ResponseField>
  </Expandable>
  </ResponseField>
</Expandable>
</ResponseField>
