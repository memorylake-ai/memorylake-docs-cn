---
title: "移除用户组成员"
description: "将一名成员移出用户组"
---

```
DELETE /openapi/memorylake/admin/v1/access-groups/{group_id}/members/{principal_id}
```

将一名成员移出用户组。若该主体不在用户组中，返回 404。

<Note>
**所需权限：** `access_group:manage`

- 如果改动会让某人获得管理员角色，或会缩小管理员能访问的范围，还需要由团队所有者或管理员操作。
</Note>

### 路径参数

<ParamField path="group_id" type="string" required>
标识符
</ParamField>

<ParamField path="principal_id" type="string" required>
要移除的成员
</ParamField>

### 请求头

<ParamField header="Idempotency-Key" type="string">
可选。使用相同值重试会重放首次结果。
</ParamField>

<RequestExample>
```bash cURL
curl -X DELETE 'https://app.memorylake.cn/openapi/memorylake/admin/v1/access-groups/7013fb5c15cfb29411f040967354b8a3/members/dbcf9a3aabee5042775269c9d137a2f8' \
  -H 'Authorization: Bearer sk_xxxxxx' \
  -H 'Idempotency-Key: 7c1d2e3f-0a9b-4c8d-b7e6-f5a4d3c2b1a0'
```
</RequestExample>

### 响应

<ResponseExample>
```json Success (200)
{
  "success": true,
  "message": "Operation completed successfully",
  "data": {}
}
```
</ResponseExample>
