---
title: "创建用户组"
description: "创建用户组"
---

```
POST /openapi/memorylake/admin/v1/access-groups
```

创建用户组。其权限来自一个可选基础——角色（`base_role_key`）或另一个用户组（`base_access_group_id`），在创建时固定——加上其自身的权限列表。仅所有者或管理员可创建基于 `tenant_admin` 的用户组。每个团队最多 200 个用户组。

<Note>
**所需权限：** `access_group:manage`

- 如果改动会让某人获得管理员角色，或会缩小管理员能访问的范围，还需要由团队所有者或管理员操作。
</Note>

### 请求头

<ParamField header="Idempotency-Key" type="string">
可选。使用相同值重试会重放首次结果，而不会创建第二个用户组。
</ParamField>

### 请求体

<ParamField body="name" type="string" required>
显示名称
</ParamField>

<ParamField body="base_access_group_id" type="string">
可选，与 `base_role_key` 互斥。该用户组授予此用户组所授予的全部权限。
</ParamField>

<ParamField body="base_role_key" type="string">
可选。该用户组授予此角色所授予的全部权限。授予 `tenant_admin` 需要所有者或管理员。可选值：`tenant_member`、`tenant_admin`。
</ParamField>

<ParamField body="description" type="string">
可选描述
</ParamField>

<ParamField body="permissions" type="array">
在基础之上额外授予的可选权限
<Expandable title="Access Group Permission 对象">
  <ParamField body="permissions[].action" type="string" required>操作</ParamField>
  <ParamField body="permissions[].resource_type" type="string" required>资源类型（参见 `GET /permission-catalog?grantable_to=access_group`）</ParamField>
</Expandable>
</ParamField>

<RequestExample>

```bash cURL
  -H 'Authorization: Bearer sk_xxxxxx' \

  -d '{
    "name": "Example name",
    "base_access_group_id": "654c7f7dfc968117cbb5a2e1e31a838e",

    "description": "Example description",
    "permissions": [
      {
        "action": "example",

      }
    ]
  }'
```
</RequestExample>

### 错误

| 状态码 | 含义 |
| --- | --- |
| `400` | 参数或请求体无效 |
| `401` | API Key 缺失、无效、已停用或已过期 |
| `403` | 该 Key 无权执行此操作 |
| `404` | 资源不存在 |
| `409` | 请求与当前状态冲突，例如重复或已达上限 |
| `422` | 请求体或参数未通过校验 |
| `429` | 请求过多，请按 `Retry-After` 等待后重试 |
| `500` | 服务端错误 |
| `503` | 暂时不可用，请稍后重试 |
