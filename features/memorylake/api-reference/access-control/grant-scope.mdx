---
title: "授予访问权限"
description: "让访问范围受限的成员或用户组可以访问某个资源"
---

```
PUT /openapi/memorylake/admin/v1/access/{resource_type}/{resource_id}/scope-grants/{subject_type}/{subject_id}
```

把该资源加入某个成员或用户组的访问范围（对方在这类资源上的访问范围受限），让对方可以用已有的权限访问它。

| `resource_type` | `resource_id` 取值 | 所需权限 |
|---|---|---|
| `workspaces` | `workspace_id` | `workspace:assign`（作用于 `workspace_id`）或 `member:set_scope`（`subject_type` 为 `members` 时）或 `access_group:manage`（`subject_type` 为 `access-groups` 时）<br />同时需要：`workspace:assign`（作用于 `workspace_id`）或 `access_group:view`<br />同时需要：`workspace:read`（作用于 `workspace_id`） |
| `projects` | `project_id` | `project:assign`（作用于 `project_id`）或 `member:set_scope`（`subject_type` 为 `members` 时）或 `access_group:manage`（`subject_type` 为 `access-groups` 时）<br />同时需要：`project:assign`（作用于 `project_id`）或 `access_group:view`<br />同时需要：`project:read`（作用于 `project_id`） |
| `actors` | `actor_id` | `actor:assign`（作用于 `actor_id`）或 `member:set_scope`（`subject_type` 为 `members` 时）或 `access_group:manage`（`subject_type` 为 `access-groups` 时）<br />同时需要：`actor:assign`（作用于 `actor_id`）或 `access_group:view`<br />同时需要：`actor:read`（作用于 `actor_id`） |
| `agents` | `agent_id` | `agent:assign`（作用于 `agent_id`）或 `member:set_scope`（`subject_type` 为 `members` 时）或 `access_group:manage`（`subject_type` 为 `access-groups` 时）<br />同时需要：`agent:assign`（作用于 `agent_id`）或 `access_group:view`<br />同时需要：`agent:read`（作用于 `agent_id`） |
| `skills` | `skill_id` | `skill:assign`（作用于 `skill_id`）或 `member:set_scope`（`subject_type` 为 `members` 时）或 `access_group:manage`（`subject_type` 为 `access-groups` 时）<br />同时需要：`skill:assign`（作用于 `skill_id`）或 `access_group:view`<br />同时需要：`skill:read`（作用于 `skill_id`） |
| `boundaries` | `boundary_id` | `boundary:assign`（作用于 `boundary_id`）或 `member:set_scope`（`subject_type` 为 `members` 时）或 `access_group:manage`（`subject_type` 为 `access-groups` 时）<br />同时需要：`boundary:assign`（作用于 `boundary_id`）或 `access_group:view`<br />同时需要：`boundary:read`（作用于 `boundary_id`） |
| `workspaces/{workspace_id}/actors` | `actor_id` | `workspace_actor:assign`（作用于 `workspace_id}/{actor_id`）或 `member:set_scope`（`subject_type` 为 `members` 时）或 `access_group:manage`（`subject_type` 为 `access-groups` 时）<br />同时需要：`workspace_actor:assign`（作用于 `workspace_id}/{actor_id`）或 `access_group:view`<br />同时需要：`workspace_actor:read`（作用于 `workspace_id}/{actor_id`） |
| `workspaces/{workspace_id}/agents` | `agent_id` | `workspace_agent:assign`（作用于 `workspace_id}/{agent_id`）或 `member:set_scope`（`subject_type` 为 `members` 时）或 `access_group:manage`（`subject_type` 为 `access-groups` 时）<br />同时需要：`workspace_agent:assign`（作用于 `workspace_id}/{agent_id`）或 `access_group:view`<br />同时需要：`workspace_agent:read`（作用于 `workspace_id}/{agent_id`） |

### 路径参数

<ParamField path="resource_type" type="string" required>
资源类型，取上表中的值之一
</ParamField>

<ParamField path="resource_id" type="string" required>
资源 ID，取值见上表
</ParamField>

<ParamField path="subject_type" type="string" required>
`members` 或 `access-groups`
</ParamField>

<ParamField path="subject_id" type="string" required>
成员的 `principal_id`，或用户组 ID
</ParamField>

### 请求头

<ParamField header="Idempotency-Key" type="string">
可选。使用相同值重试会重放首次结果。
</ParamField>

### 请求体

<ParamField body="reason" type="string" required>
变更原因；记录在审计日志中
</ParamField>

<ParamField body="workspace_id" type="string">
仅限项目：项目所属的工作空间，以便在访问范围中按名称显示项目
</ParamField>

<RequestExample>
```bash cURL
curl -X PUT 'https://app.memorylake.cn/openapi/memorylake/admin/v1/access/workspaces/69e585312c30a734cd7727316b1918bd/scope-grants/members/89914667f74821b220f374d323f0f4b0' \
  -H 'Authorization: Bearer sk_xxxxxx' \
  -H 'Idempotency-Key: 7c1d2e3f-0a9b-4c8d-b7e6-f5a4d3c2b1a0' \
  -H 'Content-Type: application/json' \
  -d '{
    "reason": "example",
    "workspace_id": "ca1916805adbcec16aceaaf65c1a4b74"
  }'
```
</RequestExample>
