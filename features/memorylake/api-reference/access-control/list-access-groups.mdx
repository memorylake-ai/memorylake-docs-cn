---
title: "列出用户组"
description: "列出您团队的用户组"
---

```
GET /openapi/memorylake/admin/v1/access-groups
```

列出您团队的用户组。用户组为其成员授予额外的权限以及对额外实例的访问权限；它从不收回访问权限。

<Note>
**所需权限：** `access_group:view`
</Note>

### 查询参数

<ParamField query="page_size" type="integer">
每页条数，1–100（默认 20）
</ParamField>

<ParamField query="continuation_token" type="string">
上一页返回的令牌
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.cn/openapi/memorylake/admin/v1/access-groups' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### 错误

出错时返回 `success: false`、`message` 和 `error_code`。全部错误码见[错误码](/features/memorylake/api-reference/errors)。

| 状态码 | 含义 |
| --- | --- |
| `400` | 参数或请求体无效 |
| `401` | API Key 缺失、无效、已停用或已过期 |
| `403` | 该 Key 无权执行此操作 |
| `422` | 请求体或参数未通过校验 |
| `429` | 请求过多，请按 `Retry-After` 等待后重试 |
| `500` | 服务端错误 |
