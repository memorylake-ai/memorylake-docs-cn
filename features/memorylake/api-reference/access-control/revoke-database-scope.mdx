---
title: "撤销数据库资源访问权限"
description: "把数据库资源移出受限的访问范围"
noindex: true
---

```
DELETE /openapi/memorylake/admin/v1/access/{resource_type}/{resource_id}/scope-grants/{subject_type}/{subject_id}
```

针对数据库连接、数据源和分析模型的[撤销访问权限](/features/memorylake/api-reference/access-control/revoke-scope)。

| `resource_type` | `resource_id` 取值 | 所需权限 |
|---|---|---|
| `db-connections` | `connection_id` | `dbconn:assign`（作用于 `connection_id`）或 `member:set_scope`（`subject_type` 为 `members` 时）或 `access_group:manage`（`subject_type` 为 `access-groups` 时）<br />同时需要：`dbconn:assign`（作用于 `connection_id`）或 `access_group:view`<br />同时需要：`dbconn:read`（作用于 `connection_id`） |
| `db-datasources` | `datasource_id` | `db_datasource:assign`（作用于 `datasource_id`）或 `member:set_scope`（`subject_type` 为 `members` 时）或 `access_group:manage`（`subject_type` 为 `access-groups` 时）<br />同时需要：`db_datasource:assign`（作用于 `datasource_id`）或 `access_group:view`<br />同时需要：`db_datasource:read`（作用于 `datasource_id`） |
| `analysis-models` | `model_id` | `analysis_model:assign`（作用于 `model_id`）或 `member:set_scope`（`subject_type` 为 `members` 时）或 `access_group:manage`（`subject_type` 为 `access-groups` 时）<br />同时需要：`analysis_model:assign`（作用于 `model_id`）或 `access_group:view`<br />同时需要：`analysis_model:read`（作用于 `model_id`） |

<Note>
- 如果改动会让某人获得管理员角色，或会缩小管理员能访问的范围，还需要由团队所有者或管理员操作。
</Note>

### 路径参数

<ParamField path="resource_type" type="string" required>
资源类型，取上表中的值之一
</ParamField>

<ParamField path="resource_id" type="string" required>
资源 ID，取值见上表
</ParamField>

<ParamField path="subject_type" type="string" required>
`members` 或 `access-groups`
</ParamField>

<ParamField path="subject_id" type="string" required>
成员的 `principal_id`，或用户组 ID
</ParamField>

### 查询参数

<ParamField query="reason" type="string">
记录到审计日志中的可选原因
</ParamField>

### 请求头

<ParamField header="Idempotency-Key" type="string">
可选。使用相同值重试会重放首次结果。
</ParamField>

  -H 'Authorization: Bearer sk_xxxxxx' \

### 错误

出错时返回 `success: false`、`message` 和 `error_code`。全部错误码见[错误码](/features/memorylake/api-reference/errors)。

| 状态码 | 含义 |
| --- | --- |
| `400` | 参数或请求体无效 |
| `401` | API Key 缺失、无效、已停用或已过期 |
| `403` | 该 Key 无权执行此操作 |
| `404` | 资源不存在 |
| `409` | 请求与当前状态冲突，例如重复或已达上限 |
| `422` | 请求体或参数未通过校验 |
| `429` | 请求过多，请按 `Retry-After` 等待后重试 |
| `500` | 服务端错误 |
| `503` | 暂时不可用，请稍后重试 |
