---
title: "列出成员"
description: "列出您团队的成员"
---

```
GET /openapi/memorylake/admin/v1/members
```

列出您团队的成员。任何成员都可读取成员名单；联系方式（`email`、`username`）仅返回给所有者和管理员。

<Note>
**所需权限：** 无——团队任一成员的 Key 都可以调用

- 设置了 `email` 时：团队所有者或管理员
</Note>

### 查询参数

<ParamField query="page_size" type="integer" default="20">
每页条目数（1–100）
</ParamField>

<ParamField query="continuation_token" type="string">
上一页返回的令牌。不透明——请勿自行构造或解析。
</ParamField>

<ParamField query="name_fuzzy" type="string">
按成员显示名称进行不区分大小写的子串匹配。对团队所有者和管理员，还会匹配邮箱和用户名。
</ParamField>

<ParamField query="role" type="string">
仅返回 `role` 字段为此角色键的成员（`tenant_owner`、`tenant_admin`、`tenant_member` 或自定义角色键）。未知的角色键不匹配任何成员。
</ParamField>

<ParamField query="email" type="array">
仅返回这些邮箱地址的成员（不区分大小写，精确匹配）。如需多个，请重复该参数。联系方式仅对所有者和管理员可见，此筛选条件同样如此：其他人会收到 403。
</ParamField>

<ParamField query="member_type" type="string">
仅真人成员或仅虚拟成员。可选值：`human`、`virtual`。
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.cn/openapi/memorylake/admin/v1/members' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### 错误

出错时返回 `success: false`、`message` 和 `error_code`。全部错误码见[错误码](/features/memorylake/api-reference/errors)。

| 状态码 | 含义 |
| --- | --- |
| `400` | 参数或请求体无效 |
| `401` | API Key 缺失、无效、已停用或已过期 |
| `403` | 该 Key 无权执行此操作 |
| `422` | 请求体或参数未通过校验 |
| `429` | 请求过多，请按 `Retry-After` 等待后重试 |
| `500` | 服务端错误 |
