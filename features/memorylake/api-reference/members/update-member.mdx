---
title: "更新成员"
description: "更改成员的角色和/或成员级用量上限"
---

```
PATCH /openapi/memorylake/admin/v1/members/{principal_id}
```

更改成员的角色和/或成员级用量上限。仅更改您发送的字段；不接受 `null`。此处不可分配所有者角色，也不可更改所有者本人的角色和您自己的角色——如需把团队交给另一名成员，请使用[转让所有权](/features/memorylake/api-reference/team/transfer-ownership)。您只能更改级别低于您的成员：管理员不能更改另一名管理员，除所有者外任何人都不能更改管理员（403 `MEMBER_NOT_BELOW_CALLER`）——角色与用量上限都是如此。管理员级角色（见 GET /roles 的 `admin_grant_only`）只能由所有者授予（403 `ROLE_REQUIRES_OWNER`），且永远不能授予虚拟成员（400 `ROLE_NOT_FOR_VIRTUAL_MEMBER`）。控制台遵循相同规则。

<Note>
**所需权限：** 取决于您发送的内容：

- 发送了 `role` 时：`member:change_role`
- 发送了 `max_tokens` 时：`member:set_quota`
- 所分配的角色属于管理员级：`tenant_admin`，或持有任一仅限管理员的团队操作的自定义角色时：仅团队所有者
- 该成员级别不低于您：所有者、管理员，或持有管理员级自定义角色的成员（403 `MEMBER_NOT_BELOW_CALLER`）——角色与 `max_tokens` 都是如此时：仅团队所有者
</Note>

### 路径参数

<ParamField path="principal_id" type="string" required>
成员的标识符（`principal_id`）
</ParamField>

### 请求头

<ParamField header="Idempotency-Key" type="string">
可选。使用相同值重试会重放首次结果。
</ParamField>

### 请求体

<ParamField body="max_tokens" type="integer">
每位成员的用量上限，单位 tokens，最多 1374389534。0 表示取消上限。
</ParamField>

<ParamField body="role" type="string">
新角色：`tenant_admin`、`tenant_member` 或本团队的自定义角色键。此处不能指定所有者角色。
</ParamField>

<RequestExample>
```bash cURL
curl -X PATCH 'https://app.memorylake.cn/openapi/memorylake/admin/v1/members/dbcf9a3aabee5042775269c9d137a2f8' \
  -H 'Authorization: Bearer sk_xxxxxx' \
  -H 'Idempotency-Key: 7c1d2e3f-0a9b-4c8d-b7e6-f5a4d3c2b1a0' \
  -H 'Content-Type: application/json' \
  -d '{
    "max_tokens": 1200000,
    "role": "tenant_member"
  }'
```
</RequestExample>

### 错误

出错时返回 `success: false`、`message` 和 `error_code`。全部错误码见[错误码](/features/memorylake/api-reference/errors)。

| 状态码 | 含义 |
| --- | --- |
| `400` | 参数或请求体无效 |
| `401` | API Key 缺失、无效、已停用或已过期 |
| `403` | 该 Key 无权执行此操作 |
| `404` | 资源不存在 |
| `409` | 请求与当前状态冲突，例如重复或已达上限 |
| `422` | 请求体或参数未通过校验 |
| `429` | 请求过多，请按 `Retry-After` 等待后重试 |
| `500` | 服务端错误 |
| `503` | 暂时不可用，请稍后重试 |
