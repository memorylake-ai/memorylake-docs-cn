---
title: "列出发票"
description: "列出团队的发票，按时间倒序，可按状态筛选"
---

```
GET /openapi/memorylake/admin/v1/billing/invoices
```

列出团队的发票，按时间倒序，可按状态筛选。

<Note>
**所需权限：** `invoice:read`
</Note>

### 查询参数

<ParamField query="status" type="array">
可重复。仅返回处于这些状态的发票
</ParamField>

<ParamField query="page_size" type="integer" default="20">
每页条数（1–100）
</ParamField>

<ParamField query="continuation_token" type="string">
上一页返回的令牌
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.cn/openapi/memorylake/admin/v1/billing/invoices' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### 响应

<ResponseField name="data" type="object">
<Expandable title="Load More Response Billing Invoice 对象">
  <ResponseField name="items" type="array">
