---
title: "列出订单"
description: "列出团队的支付订单，按时间倒序，可按类型和状态筛选"
---

```
GET /openapi/memorylake/admin/v1/billing/orders
```

列出团队的支付订单，按时间倒序，可按类型和状态筛选。

<Note>
**所需权限：** `order:read`
</Note>

### 查询参数

<ParamField query="type" type="string">
仅返回此类型的订单。可选值：`onetime`、`auto_topup`、`subscription`。
</ParamField>

<ParamField query="status" type="string">
仅返回此状态的订单。可选值：`pending`、`succeeded`、`failed`、`closed`、`refunded`、`disputed`。
</ParamField>

<ParamField query="page_size" type="integer" default="20">
每页条数（1–100）
</ParamField>

<ParamField query="continuation_token" type="string">
上一页返回的令牌
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.cn/openapi/memorylake/admin/v1/billing/orders' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### 响应

<ResponseField name="data" type="object">

    <ResponseField name="status" type="string">付款状态；`closed` = 付款前已放弃。可选值：`pending`、`succeeded`、`failed`、`closed`、`refunded`、`disputed`。</ResponseField>

    <ResponseField name="refunded_amount" type="object">
    退款金额（如有）
    <Expandable title="Money 对象">

      <ResponseField name="currency" type="string">小写的 ISO 4217 货币代码</ResponseField>
    </Expandable>
    </ResponseField>
    <ResponseField name="refunded_at" type="integer">Unix 秒级时间戳</ResponseField>
  </Expandable>
  </ResponseField>
  <ResponseField name="continuation_token" type="string">用于获取下一页的令牌；最后一页不返回</ResponseField>
  <ResponseField name="total" type="integer">所有分页中符合筛选条件的条目总数；无法获取计数时省略</ResponseField>
</Expandable>
</ResponseField>

### 错误

出错时返回 `success: false`、`message` 和 `error_code`。全部错误码见[错误码](/features/memorylake/api-reference/errors)。

| 状态码 | 含义 |
| --- | --- |
| `400` | 参数或请求体无效 |
| `401` | API Key 缺失、无效、已停用或已过期 |
| `403` | 该 Key 无权执行此操作 |
| `422` | 请求体或参数未通过校验 |
| `429` | 请求过多，请按 `Retry-After` 等待后重试 |
| `500` | 服务端错误 |
