---
title: "列出支付方式"
description: "列出已保存的卡片：卡组织、卡号后四位、到期时间以及哪张为默认卡"
---

```
GET /openapi/memorylake/admin/v1/billing/payment-methods
```

列出已保存的卡片：卡组织、卡号后四位、到期时间以及哪张为默认卡。添加、移除和设置默认卡需在控制台中完成。

<Note>
**所需权限：** `credits:manage`
</Note>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.cn/openapi/memorylake/admin/v1/billing/payment-methods' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### 响应

</Expandable>
</ResponseField>

### 错误

出错时返回 `success: false`、`message` 和 `error_code`。全部错误码见[错误码](/features/memorylake/api-reference/errors)。

| 状态码 | 含义 |
| --- | --- |
| `401` | API Key 缺失、无效、已停用或已过期 |
| `403` | 该 Key 无权执行此操作 |
| `429` | 请求过多，请按 `Retry-After` 等待后重试 |
| `500` | 服务端错误 |
| `503` | 暂时不可用，请稍后重试 |
