---
title: "预览套餐变更"
description: "预估在不做其他更改的情况下将订阅切换到 `plan_id` 的费用：立即收取的按比例折算金额、其明细项、变更生效时间以及下一张完整发票"
---

```
GET /openapi/memorylake/admin/v1/billing/subscription/plan-change-preview
```

预估在不做其他更改的情况下将订阅切换到 `plan_id` 的费用：立即收取的按比例折算金额、其明细项、变更生效时间以及下一张完整发票。`proration_date` 回显计算按比例折算所依据的时刻。无需费用的切换会返回 `applicable` 为 false 并附带原因。变更套餐本身需在控制台中完成。

<Note>
**所需权限：** `subscription:manage`
</Note>

### 查询参数

<ParamField query="plan_id" type="integer" required>
要试算切换价格的目标套餐
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.cn/openapi/memorylake/admin/v1/billing/subscription/plan-change-preview?plan_id=9e50b1aed525a8280e28b9662b6a7ba0' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### 错误

出错时返回 `success: false`、`message` 和 `error_code`。全部错误码见[错误码](/features/memorylake/api-reference/errors)。

| 状态码 | 含义 |
| --- | --- |
| `400` | 参数或请求体无效 |
| `401` | API Key 缺失、无效、已停用或已过期 |
| `403` | 该 Key 无权执行此操作 |
| `409` | 请求与当前状态冲突，例如重复或已达上限 |
| `422` | 请求体或参数未通过校验 |
| `429` | 请求过多，请按 `Retry-After` 等待后重试 |
| `500` | 服务端错误 |
| `503` | 暂时不可用，请稍后重试 |
