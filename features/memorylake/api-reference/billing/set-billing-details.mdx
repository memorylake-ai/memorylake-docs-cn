---
title: "设置开票信息"
description: "替换已付款发票上打印的购买方信息（未提供的字段会被清空）"
---

```
PUT /openapi/memorylake/admin/v1/billing/invoices/{invoice_id}/billing-details
```

替换已付款发票上打印的购买方信息（未提供的字段会被清空）。之后下载的 PDF 将包含这些信息。

<Note>
**所需权限：** `invoice:read`
</Note>

### 路径参数

<ParamField path="invoice_id" type="string" required>
发票 ID（`invoice_id`）
</ParamField>

### 请求体

<ParamField body="address" type="string" required>
账单地址
</ParamField>

<ParamField body="invoice_type" type="string" required>
`individual` 需要 `name`；`business` 需要 `company_name`
</ParamField>

<ParamField body="company_name" type="string">
公司名称
</ParamField>

<ParamField body="contact_email" type="string">
联系邮箱
</ParamField>

<ParamField body="name" type="string">
人员姓名
</ParamField>

<ParamField body="tax_id" type="string">
纳税人识别号
</ParamField>

<RequestExample>
```bash cURL
curl -X PUT 'https://app.memorylake.cn/openapi/memorylake/admin/v1/billing/invoices/2501a637ff332794f7dc5edee0556e67/billing-details' \
  -H 'Authorization: Bearer sk_xxxxxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "address": "example",
    "invoice_type": "individual",
    "company_name": "Example company",
    "contact_email": "alice@example.com",
    "name": "Example name",
    "tax_id": "4155f354c126224a5833bdd25597ea80"
  }'
```
</RequestExample>

### 错误

出错时返回 `success: false`、`message` 和 `error_code`。全部错误码见[错误码](/features/memorylake/api-reference/errors)。

| 状态码 | 含义 |
| --- | --- |
| `400` | 参数或请求体无效 |
| `401` | API Key 缺失、无效、已停用或已过期 |
| `403` | 该 Key 无权执行此操作 |
| `404` | 资源不存在 |
| `409` | 请求与当前状态冲突，例如重复或已达上限 |
| `422` | 请求体或参数未通过校验 |
| `429` | 请求过多，请按 `Retry-After` 等待后重试 |
| `500` | 服务端错误 |
