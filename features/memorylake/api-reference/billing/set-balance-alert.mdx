---
title: "设置余额预警"
description: "替换余额预警配置"
---

```
PUT /openapi/memorylake/admin/v1/billing/credit-balance/alert
```

替换余额预警配置。阈值须全部为 `percent_used` 或全部为 `tokens_remaining`（最多 5 个）；绝对值以 tokens 为单位。收件人是在团队所有者之外追加的，团队所有者始终会收到通知。如需停止预警，请将 `enabled` 设为 false。

<Note>
**所需权限：** `credits:manage`
</Note>

### 请求体

<ParamField body="enabled" type="boolean" required>
是否发送预警
</ParamField>

<ParamField body="thresholds" type="array" required>
预警级别，须为同一类型；重复项会被去除
<Expandable title="Balance Alert Threshold 对象">
  <ParamField body="thresholds[].type" type="string" required>阈值类型；同一请求中的所有阈值必须使用相同类型。可选值：`percent_used`、`tokens_remaining`。</ParamField>
  <ParamField body="thresholds[].value" type="integer" required>`percent_used` 取 1–99；`tokens_remaining` 取 1–1,000,000,000</ParamField>
</Expandable>
</ParamField>

<ParamField body="notification_channel" type="object">
省略则仅发送给团队所有者
<Expandable title="Alert Recipients Channel 对象">
  <ParamField body="notification_channel.recipients" type="array" required>附加邮箱地址（团队所有者始终会收到预警）；重复项按不区分大小写去除</ParamField>
  <ParamField body="notification_channel.type" type="string" required>投递渠道。可选值：`email`。</ParamField>
</Expandable>
</ParamField>

<RequestExample>
```bash cURL
curl -X PUT 'https://app.memorylake.cn/openapi/memorylake/admin/v1/billing/credit-balance/alert' \
  -H 'Authorization: Bearer sk_xxxxxx' \
  -H 'Content-Type: application/json' \
  -d '{
    "enabled": true,
    "thresholds": [
      {
        "type": "percent_used",
        "value": 1
      }
    ],
    "notification_channel": {
      "recipients": [
        "example"
      ],
      "type": "email"
    }
  }'
```
</RequestExample>

### 错误

出错时返回 `success: false`、`message` 和 `error_code`。全部错误码见[错误码](/features/memorylake/api-reference/errors)。

| 状态码 | 含义 |
| --- | --- |
| `400` | 参数或请求体无效 |
| `401` | API Key 缺失、无效、已停用或已过期 |
| `403` | 该 Key 无权执行此操作 |
| `422` | 请求体或参数未通过校验 |
| `429` | 请求过多，请按 `Retry-After` 等待后重试 |
| `500` | 服务端错误 |
