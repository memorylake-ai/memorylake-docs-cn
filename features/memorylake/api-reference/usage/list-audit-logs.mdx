---
title: "列出审计日志"
description: "列出团队的审计事件，按时间倒序：管理变更（类别 `management`）以及平台自行记录的事件（类别 `system`）"
---

```
GET /openapi/memorylake/admin/v1/audit-logs
```

列出团队的审计事件，按时间倒序：管理变更（类别 `management`）以及平台自行记录的事件（类别 `system`）。通过此 API 使用 API Key 进行的变更会标明该 Key（`actor.type` 为 `api_key`）。持有 `log:read_all` 时列表覆盖整个团队；仅持有 `log:read_self` 的调用方只能看到自己执行的事件，按其他成员的 `actor_id` 筛选会被拒绝。时间窗口默认为最近 7 天，最长 92 天。与其他列表不同，此列表不返回总数——请使用 `continuation_token` 持续翻页，直到其不再返回。限流：默认每个 Key 每分钟 20 次请求，与其他所有操作分开计数。翻阅大量记录时，请使用最大的 `page_size`（100）。

<Note>
**所需权限：** `log:read_all`（全团队）或 `log:read_self`（仅本人）

- 按其他成员的 `actor_id` 筛选时：`log:read_all`
</Note>

### 查询参数

<ParamField query="page_size" type="integer" default="20">
每页条目数（1–100）
</ParamField>

<ParamField query="continuation_token" type="string">
上一页返回的令牌。不透明——请勿自行构造或解析。请同时发送相同的筛选条件。
</ParamField>

<ParamField query="category" type="string">
`management`：人员对团队所做的变更及 Key 操作（成员、角色、Key、计费设置）。`system`：平台自行记录的事件（订阅结束、余额预警等）。省略则两者都包含。
</ParamField>

<ParamField query="action" type="array">
仅返回这些操作，例如 `member:change_role`。如需多个，请重复该参数。
</ParamField>

<ParamField query="actor_id" type="array">
仅返回由这些成员（`principal_id`）执行的事件。如需多个，请重复该参数。仅限查看自己事件的调用方只能传自己的 ID。
</ParamField>

<ParamField query="target_type" type="string">
仅返回目标为此类型的事件，例如 `principal`、`service_account`。
</ParamField>

<ParamField query="target_id" type="string">
仅返回目标为此 ID 的事件。
</ParamField>

<ParamField query="result" type="string">
仅返回此结果的事件。可选值：`succeeded`、`failed`、`partial`。
</ParamField>

<ParamField query="start_time" type="integer">
要包含的最早事件时间，Unix 秒级时间戳（含）。默认为 `end_time` 前 7 天。
</ParamField>

<ParamField query="end_time" type="integer">
事件时间上限，Unix 秒级时间戳（不含）。默认为当前时间。时间窗口最长 92 天。
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.cn/openapi/memorylake/admin/v1/audit-logs' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>
