---
title: "获取用量"
description: "返回当前额度快照以及所请求周期内的用量（最多 92 天）"
---

```
GET /openapi/memorylake/admin/v1/usage
```

返回当前额度快照以及所请求周期内的用量（最多 92 天）。持有 `usage:view_all` 时数据覆盖整个团队；仅持有 `usage:view_self` 的调用方获得自己的用量（包括其 API Key），并由 `scope` 指明是哪一种。`bucket_width=1d` 会额外返回按天的序列；`group_by=member` 会额外返回按成员的明细，且需要 `usage:view_all`。

<Note>
**所需权限：** `usage:view_all`（全团队）或 `usage:view_self`（仅本人）

- 传入 `group_by=member` 时：`usage:view_all`
</Note>

### 查询参数

<ParamField query="start_date" type="string">
要包含的第一天，YYYY-MM-DD，按 `period.timezone` 所示时区计算。默认为 `end_date` 前六天。
</ParamField>

<ParamField query="end_date" type="string">
要包含的最后一天，YYYY-MM-DD，按 `period.timezone` 所示时区计算。默认为今天。
</ParamField>

<ParamField query="bucket_width" type="string">
设为 `1d` 可同时获取 `buckets`：该周期内按天的时间序列。
</ParamField>

<ParamField query="group_by" type="array">
可重复。`by_model` 始终针对该周期返回；`member` 会额外返回 `by_member`（需要 `usage:view_all`）。当 `bucket_width=1d` 时，每个桶也携带此处列出的明细。
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.cn/openapi/memorylake/admin/v1/usage' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### 错误

出错时返回 `success: false`、`message` 和 `error_code`。全部错误码见[错误码](/features/memorylake/api-reference/errors)。

| 状态码 | 含义 |
| --- | --- |
| `400` | 参数或请求体无效 |
| `401` | API Key 缺失、无效、已停用或已过期 |
| `403` | 该 Key 无权执行此操作 |
| `422` | 请求体或参数未通过校验 |
| `429` | 请求过多，请按 `Retry-After` 等待后重试 |
| `500` | 服务端错误 |
