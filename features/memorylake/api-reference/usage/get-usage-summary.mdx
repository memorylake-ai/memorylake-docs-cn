---
title: "获取用量汇总"
description: "返回今日、最近 7 天及本月至今的用量"
---

```
GET /openapi/memorylake/admin/v1/usage/summary
```

返回今日、最近 7 天及本月至今的用量。范围规则和数据与[获取用量](/features/memorylake/api-reference/usage/get-usage)相同（包含平台计量操作）：持有 `usage:view_all` 时为整个团队，否则为调用方自己的用量。

<Note>
**所需权限：** `usage:view_all`（全团队）或 `usage:view_self`（仅本人）
</Note>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.cn/openapi/memorylake/admin/v1/usage/summary' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### 错误

出错时返回 `success: false`、`message` 和 `error_code`。全部错误码见[错误码](/features/memorylake/api-reference/errors)。

| 状态码 | 含义 |
| --- | --- |
| `401` | API Key 缺失、无效、已停用或已过期 |
| `403` | 该 Key 无权执行此操作 |
| `429` | 请求过多，请按 `Retry-After` 等待后重试 |
| `500` | 服务端错误 |
