---
title: "更新 IM 集成"
description: "更改 IM 集成"
---

```
PATCH /openapi/memorylake/admin/v1/integrations/{integration_id}
```

更改 IM 集成。仅更改您发送的字段；不接受 `null`。省略 `credentials` 则保留原凭据；仅发送新的 secret 即可轮换。机器人的应用标识符不可更改（422）。新的 DingTalk、Feishu 和 Slack 凭据会在保存前验证，状态会回到 `pending`，直至新连接建立。更改项目引用所需的项目访问权限与[创建 IM 集成](/features/memorylake/api-reference/integrations/create-integration)相同。

<Note>
**所需权限：** `workspace:integration_manage`（作用于 `workspace_id`）

- 设置了 `read_write_project_id` 时：`project:mem_add`（作用于 `read_write_project_id`）
- 设置了 `read_only_project_ids` 时：`project:mem_search`（作用于 `read_only_project_ids`）
</Note>

### 路径参数

<ParamField path="integration_id" type="string" required>
集成的标识符
</ParamField>

### 请求头

<ParamField header="Idempotency-Key" type="string">
可选。使用相同值重试会重放首次结果。不比较凭据值。
</ParamField>

### 请求体

<ParamField body="agent_id" type="string">
切换应答的 Agent。进行中的 IM 会话将以新 Agent 重新开始；发送当前的 `agent_id` 不会产生任何变化。
</ParamField>

<ParamField body="credentials" type="object">
仅可写入。省略则保留已存储的凭据。只需发送有变化的值：可单独轮换密钥。应用标识符（`appKey` / `appId` / `botId`，或 Slack 团队与机器人用户）无法更改——如需连接其他机器人，请删除并重新创建集成。DingTalk、Feishu 和 Slack 的凭据会在保存前向平台校验。
<Expandable title="Integration Credentials 对象">
  <ParamField body="credentials.appId" type="string">飞书：App ID。用于标识机器人；创建后不可更改。</ParamField>
  <ParamField body="credentials.appKey" type="string">DingTalk：Client ID（AppKey）。用于标识机器人；创建后不可更改。</ParamField>
  <ParamField body="credentials.appSecret" type="string">DingTalk：Client Secret（AppSecret）。Feishu：App Secret。</ParamField>
  <ParamField body="credentials.appToken" type="string">Slack：具有 `connections:write` 权限的 App-Level Token（`xapp-…`）。</ParamField>
  <ParamField body="credentials.botId" type="string">WeCom：智能机器人的 Bot ID。用于标识机器人；创建后不可更改。</ParamField>
  <ParamField body="credentials.botToken" type="string">Slack：Bot User OAuth Token（`xoxb-…`）。不支持启用了令牌轮换的应用。</ParamField>
  <ParamField body="credentials.secret" type="string">WeCom：智能机器人的 Secret。</ParamField>
</Expandable>
</ParamField>

<ParamField body="daily_message_limit" type="integer">
每天处理的最大消息数；0 表示不限
</ParamField>

<ParamField body="dataset_ids" type="array">
替换数据集。`[]` 表示移除。
</ParamField>

<ParamField body="enabled" type="boolean">
连接（`true`）或断开（`false`）机器人
</ParamField>

<ParamField body="name" type="string">
新显示名称
</ParamField>

<ParamField body="read_only_project_ids" type="array">
替换只读项目。`[]` 表示移除。
</ParamField>

<ParamField body="read_write_project_id" type="string">
提炼出的记忆所归入的新项目
</ParamField>

<ParamField body="settings" type="object">
替换渠道特定的设置
<Expandable title="Integration Settings 对象">
  <ParamField body="settings.card_template_id" type="string">仅限 DingTalk：AI 卡片模板 ID。设置后回复将以流式写入交互卡片；省略或发送 `""` 则以普通消息回复。</ParamField>
</Expandable>
</ParamField>

### 错误

出错时返回 `success: false`、`message` 和 `error_code`。全部错误码见[错误码](/features/memorylake/api-reference/errors)。

| 状态码 | 含义 |
| --- | --- |
| `400` | 参数或请求体无效 |
| `401` | API Key 缺失、无效、已停用或已过期 |
| `403` | 该 Key 无权执行此操作 |
| `404` | 资源不存在 |
| `409` | 请求与当前状态冲突，例如重复或已达上限 |
| `422` | 请求体或参数未通过校验 |
| `429` | 请求过多，请按 `Retry-After` 等待后重试 |
| `500` | 服务端错误 |
| `503` | 暂时不可用，请稍后重试 |
