---
title: "获取 IM 集成"
description: "返回一个集成"
---

```
GET /openapi/memorylake/admin/v1/integrations/{integration_id}
```

返回一个集成。创建或更改凭据后可轮询此接口，以跟踪 `status`（`pending` → `connected` 或 `error`）和 `status_error`。其他团队的集成会报告为未找到。

<Note>
**所需权限：** `workspace:integration_manage`（作用于 `workspace_id`）
</Note>

### 路径参数

<ParamField path="integration_id" type="string" required>
集成的标识符
</ParamField>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.cn/openapi/memorylake/admin/v1/integrations/8e6332af9d801f19496ca0f9fded5333' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### 响应

<ResponseField name="data" type="object">
<Expandable title="Integration 对象">
  <ResponseField name="agent_id" type="string">负责回复发送给该机器人的消息的 Agent</ResponseField>
  <ResponseField name="channel" type="string">IM 平台。可选值：`dingtalk`、`wecom`、`feishu`、`slack`。</ResponseField>
  <ResponseField name="created_at" type="integer">创建时间，Unix 秒级时间戳</ResponseField>
  <ResponseField name="credentials_configured" type="boolean">是否已存储凭据。凭据本身仅可写入，从不返回。</ResponseField>
  <ResponseField name="daily_message_limit" type="integer">此集成每天处理的最大消息数；0 表示不限</ResponseField>
  <ResponseField name="dataset_ids" type="array">Agent 可使用的开放数据数据集</ResponseField>
  <ResponseField name="enabled" type="boolean">是否应连接该集成</ResponseField>
  <ResponseField name="external_app_id" type="string">机器人在 IM 平台上的标识符（DingTalk Client ID、Feishu App ID、WeCom Bot ID、Slack `team:bot-user`）。不属于机密信息。</ResponseField>
  <ResponseField name="id" type="string">集成的标识符</ResponseField>
  <ResponseField name="name" type="string">显示名称</ResponseField>
  <ResponseField name="read_only_project_ids" type="array">额外检索的项目（只读）</ResponseField>
  <ResponseField name="read_write_project_id" type="string">从 IM 对话中提取的记忆写入的项目</ResponseField>
  <ResponseField name="settings" type="object">
  渠道专属设置
  <Expandable title="Integration Settings 对象">
    <ResponseField name="card_template_id" type="string">仅限 DingTalk：AI 卡片模板 ID。设置后回复将以流式写入交互卡片；省略或发送 `""` 则以普通消息回复。</ResponseField>
  </Expandable>
  </ResponseField>
  <ResponseField name="status" type="string">连接状态。创建后或更改凭据后为 `pending`，直至首次连接尝试；可轮询[获取 IM 集成](/features/memorylake/api-reference/integrations/get-integration)跟踪状态。可选值：`pending`、`connected`、`error`、`disabled`。</ResponseField>
  <ResponseField name="updated_at" type="integer">最后更新时间，Unix 秒级时间戳</ResponseField>
  <ResponseField name="workspace_id" type="string">集成所属的工作空间。创建时确定。</ResponseField>
  <ResponseField name="status_error" type="string">`status` 为 `error` 时的简短规范化原因，用于展示（中文，采用控制台措辞，可能变化）。绝不包含平台的原始响应。程序中请使用 `status_error_code`。</ResponseField>
  <ResponseField name="status_error_code" type="string">稳定的原因代码，只要存在 `status_error` 就会返回。`credentials_invalid`：平台拒绝了凭据（请修正凭据）；`subscribe_rejected`：WeCom 拒绝了订阅——凭据错误或触发平台限流，会自动重试；`preempted`：另一个连接接管了该机器人，通常是同一机器人在另一环境中建立了连接；`timeout` / `disconnected` / `connection_aborted` / `connection_failed`：连接问题，会自动重试；`dependency_unavailable`：此部署依赖的某项服务不可用，会自动重试；`dependency_misconfigured`：此部署缺少该渠道所需的组件（WeCom 需要 Redis）——请联系运维人员；`internal_error`：我方故障；`unknown`：该原因记录于原因代码引入之前，会在下次连接尝试时被替换。今后可能新增代码；遇到无法识别的代码时，请按 `connection_failed` 处理。</ResponseField>
</Expandable>
</ResponseField>

### 错误

出错时返回 `success: false`、`message` 和 `error_code`。全部错误码见[错误码](/features/memorylake/api-reference/errors)。

| 状态码 | 含义 |
| --- | --- |
| `401` | API Key 缺失、无效、已停用或已过期 |
| `403` | 该 Key 无权执行此操作 |
| `404` | 资源不存在 |
| `422` | 请求体或参数未通过校验 |
| `429` | 请求过多，请按 `Retry-After` 等待后重试 |
| `500` | 服务端错误 |
