---
title: "列出我的已授权应用"
description: "列出调用方（Key 的所有者）在本团队通过 MCP OAuth 授权、目前仍可访问其记忆的应用：每个应用与记忆边界一项"
---

```
GET /openapi/memorylake/admin/v1/me/authorized-apps
```

列出调用方（Key 的所有者）在本团队通过 MCP OAuth 授权、目前仍可访问其记忆的应用：每个应用与记忆边界一项。只列出您自己的授权，任何人都无法列出其他成员的授权。部署未开启 MCP OAuth 时为空。

<Note>
**所需权限：** 无——团队任一成员的 Key 都可以调用
</Note>

<RequestExample>
```bash cURL
curl -X GET 'https://app.memorylake.cn/openapi/memorylake/admin/v1/me/authorized-apps' \
  -H 'Authorization: Bearer sk_xxxxxx'
```
</RequestExample>

### 错误

出错时返回 `success: false`、`message` 和 `error_code`。全部错误码见[错误码](/features/memorylake/api-reference/errors)。

| 状态码 | 含义 |
| --- | --- |
| `401` | API Key 缺失、无效、已停用或已过期 |
| `403` | 该 Key 无权执行此操作 |
| `429` | 请求过多，请按 `Retry-After` 等待后重试 |
| `500` | 服务端错误 |
