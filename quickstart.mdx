本指南带您在约五分钟内从注册走到一份可用的记忆，然后为您指出最契合您工作方式的集成路径。

## 第 1 步：注册

在 [app.memorylake.cn](https://app.memorylake.cn) 用**邮箱 + 密码**注册账号——这是中国站当前唯一的登录方式，注册后**无需邮箱验证**即可直接使用。MemoryLake 会自动为您开通个人工作空间和助手——首次会话之前无需任何配置。

## 第 2 步：在 Playground 中体验记忆

从侧边栏打开 **Playground**（新账号会直接进入这里，并有一个简短的引导）：

<Steps>
<Step title="告诉它一件值得记住的事">
试试：*"记住我叫小明，我偏好用要点形式回答。"*

在背后，MemoryLake 会从会话中提取一条可长期沉淀的记忆——不是对话记录，而是一条事实。
</Step>

<Step title="添加 Open Data（可选）">
为您的项目订阅一个精选行业数据集——论文、金融数据、临床试验等——这样助手在检索您自有内容的同时，还能检索权威的外部来源。
</Step>

<Step title="上传文件">
直接在对话中附加 PDF、Word、Excel 或 Markdown 文件。其内容会被解析、建立索引，并成为可检索的上下文。
</Step>

<Step title="感受差异">
开启一个**新**会话并提问：*"我叫什么，我喜欢什么样的回答？"* 助手能回忆起来——这就是跨会话持续存在的记忆。首页的记忆开/关对比会并排展示同样的效果。
</Step>
</Steps>

<Tip>
在侧边栏访问**记忆**，查看提取出了什么——每条记忆都会显示其内容，以及回到它来源会话或文档的**来源溯源**。
</Tip>

## 第 3 步：创建 API Key

任何编程访问——REST API、Model Router 或 Agent 插件——都需要创建一个 API Key：

1. 在控制台侧边栏打开 **API Keys**
2. 点击创建，为 Key 命名，并选择有效期（默认 30 天；也可选择"永不过期"）
3. Key 揭示时立即复制 `sk-…`——它只显示一次

请参见[认证](/authentication)了解请求头格式和 Key 管理。

选择匹配您工作流的路径：

## 刚刚发生了什么？

您的会话和文件被提炼成了**记忆**，存放在您**工作空间**中的一个**项目**里——任何您连接的助手或 API 客户端都可检索，且范围始终限定为您私有。当您准备好与团队共享记忆时，参见[团队协作](/features/team-collaboration/overview)；要理解完整模型，请阅读[核心概念](/concepts)。
